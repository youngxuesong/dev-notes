# 隐私政策 (Privacy Policy)

**最后更新日期：2026年3月**

欢迎访问 DevNotes（“本站”）。我们高度重视您的个人隐私。本隐私政策旨在向您说明本站如何收集、使用和保护您的信息。

## 1. 我们收集的信息

作为静态技术博客，我们本身不要求您注册账号，也不会主动收集您的姓名、电话等敏感个人身份信息。

### 1.1 自动收集的访问日志与 Cookie
当您访问本站时，我们的服务器和 CDN（如 Cloudflare）可能会自动记录基础网络访问日志，包括您的 IP 地址、浏览器类型、操作系统、访问时间及请求的页面。这些数据仅用于保障系统安全和分析站点访问趋势。

### 1.2 第三方广告与 Google AdSense
- 本站使用了 **Google AdSense** 提供的广告服务。
- Google 作为第三方供应商，会使用 **Cookie** 在本站上投放广告。
- Google 对广告 Cookie 的使用使其及其合作伙伴能够根据用户对本站和/或互联网上其他网站的访问记录向用户投放广告。
- 用户可以通过访问 [Google 广告设置](https://www.google.com/settings/ads) 来选择停用个性化广告。

## 2. 数据安全
我们采用行业标准的加密协议（HTTPS / TLS）传输数据，确保您的网络通信安全。
