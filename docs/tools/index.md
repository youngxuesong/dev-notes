## 💡 为什么坚持纯前端客户端工具？

1. **隐私安全 (0 数据留存)**：API Key 与个人配置仅保存在你当前设备的 `LocalStorage`，杜绝任何中间服务器嗅探与泄露风险。
2. **零延迟与官方成本**：浏览器直接向对应的大模型网关发起请求，没有中间商加价与限速。
3. **随开随用**：无需配置 Python 依赖、无需显卡驱动与本地部署，打开网页即可立即投入生产。
