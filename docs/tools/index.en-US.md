:::info Overview
A collection of lightweight, high-performance web utilities for developers, creators, and cross-border engineers. Built with a **pure client-side architecture (BYOK model)** with zero server-side data retention.
:::

## 💡 Why Pure Client-Side Tools?

1. **Strict Privacy**: Your API keys and prompts remain in your local browser storage.
2. **Direct Speed & Direct Pricing**: Direct browser-to-gateway calls without proxy middleman overhead.
3. **Frictionless Workflow**: No Python, no Docker, and no GPU setup required.
